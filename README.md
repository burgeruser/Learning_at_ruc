课程录制的视频与课件属于老师知识产权。请同学们共同保护老师的知识产权以及尊重老师的劳动成果，仅供个人学习使用。一定不要外传，更不允许在网络上进行传播，更不能用于商业。

一些本人自己收集的资料，我也分享给大家学习，也希望大家仅供个人学习使用，不作他用。

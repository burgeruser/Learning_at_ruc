## 高级操作系统

### 名词解释

1. **进程  p508**
   - 一个执行中程序的实例（process is a running program object)
2. **虚拟内存 p559**
   - virtual memory，虚拟内存是硬件异常、硬件地址翻译、主存、磁盘文件和内核软件的完美交互，它为每个进程提供了一个大的、一致的和私有的地址空间。
3. **I/O重定向 p637**
   - 允许用户将磁盘文件和标准输入输出联系起来
4. **碎片  p591**
   1. 堆里的虽然有未使用的内存但不能用来满足分配请求，这些不能分配的块叫做碎片
5. **内部碎片 p591**
   - 内部碎片是处于区域内部或页面内部的存储块。占有这些区域或页面的进程并不能使用这个存储块。而在进程占有这块存储块时，系统无法利用它。直到进程释放它，或进程结束时，系统才有可能利用这个存储块。
6. **外部碎片 p591**
   - 外部碎片是出于任何已分配区域或页面外部的空闲存储块。这些存储块的总和可以满足当前申请的长度要求，但是由于它们的地址不连续或其他原因，使得系统无法满足当前申请。
7. **inode **
   - 用来记录文件系统对象的一些元信息数据，简称“索引节点”。本质上是一个结构体。（ext4为256B）
8. **线程 p691**
   - thread 线程就是运行在进程上下文中的逻辑流。
9. **互斥 p701**
   - 想要确保每个线程在执行它的临界区中的指令时，拥有对共享变量的互斥的访问。
10. **死锁 p721**
   - 指的是一组线程被阻塞了，等一个永远也不会为真的条件。
11. **竞争 p719**
    - 竞争是当一个程序的正确性依赖于一个线程要在另一个线程达到$y$点之前到达它的控制流中的$x$点时发生的。通常发生竞争是因为程序员假定线程将按照某种特殊的轨迹线穿过执行状态空间，而忘记了另一种准则规定：多线程的程序必须对任何可行的轨迹线都正确工作。
12. **文件系统**
    - 文件系统是用于明确存储设备或分区上的文件的方法和数据结构；即在存储设备上组织文件的方法。操作系统中负责管理和存储文件信息的软件机构称为文件管理系统，简称文件系统。由三部分组成：文件系统的接口，对对象操纵和管理的软件集合，对象及属性。
13. **无锁化**
    - 无锁化编程特指在多线程编程的时候，对线程间共享数据的并发修改不使用锁， 而采用基于硬件提供的原子操作能力来修改共享数据，进而提升性能，减少使用锁带来的互斥开销。
14. **并发 p509**
    - 一个逻辑控制流在时间上与另一个逻辑控制流重叠称为并发 concurency
15. **并行 p509**
    - 两个逻辑控制流并发地运行在不同的处理器或者计算机上称这两个流为并发
16. **异常 p502**
    - exception，异常就是控制流中的突变，用来响应处理器状态中的某些变化。
17. **信号量 p702**
    - 信号量s是具有非负整数值的全局变量，只能由两种特殊的操作来处理，这两种操作称为P和V。是解决同步不同执行线程问题的方法。



### 问答题

1. **操作系统的虚拟内存机制中，软硬件是如何配合工作的？请简要陈述**。

   1. CPU生成一个虚拟地址（VA），并把它传送给芯片上的内存存储单元（MMU）
   2. MMU生成PTE地址（PTEA），并从缓存/主存中请求这个PTE
   3. 高速缓存/主存向MMU返回PTE
   4. MMU构造物理地址，并把它传送给缓存/主存
   5. 缓存/主存返回所请求的数据字给CPU
   6. [参考链接](https://blog.csdn.net/zhaohong_bo/article/details/90170316)

   1. 虚拟化
      - 进程

3. **操作系统对上提供的抽象（Abstract）有什么优点？请给出 3 个或更多经典抽象的例子**。

      - 向应用程序提供简单一致的机制来控制复杂而大相径庭的低级硬件设备
      ```

   1. 进程 p508
      - 一个独立的逻辑控制流，它提供一个假象，好像我们独占地使用处理器
      - 一个私有的地址空间，它提供一个假象，好像我们的程序独占地使用内存系统
   2. 虚拟内存 p559
      - 它将主存看成是一个存储在磁盘上的地址空间的高速缓存，在主存中只保存活动区域，并根据需要在磁盘和主存之间来回传送数据，高效地使用主存
      - 为每个进程提供了一致的地址空间，从而简化了内存管理

4. **malloc 内存分配需要考虑哪两个指标？他们之间有什么关系？p590~p591**

   1. 最大吞吐率：
      - 吞吐率定义为每个单位时间里完成的请求数。如一个分配器1秒内完成500个分配请求和500个释放请求，那么它的吞吐率就是1000次每秒操作。
   2. 最大化内存利用率：
      - 所有进程分配的虚拟内存的全部数量是受磁盘上交换空间的数量限制的。虚拟内存是一个有限的空间，必须 高效地使用。
   3. 关系：
      - 最大化吞吐率与最大化利用率之间是互相牵制的。以堆利用率为代价，很容易编写出吞吐率最大化的分配器。分配器设计中一个有趣的挑战就是在两个目标之间找到一个适当的平衡。

5. **典型的磁盘调度算法有哪些，请至少说出三种以上，并简单介绍其优缺点。**
   1. 最短寻道时间第一（Shortest Seek Time First)
      - 在最近的轨道上选择请求
      - 优缺点：
        - 饥饿
        - 陷入局部最优，达不到全局最优
   2. F-Scan (Elevator)
      - 由外到内，或内到外，一个方向扫完之后才处理新来的请求
      - 优缺点：
        - 避免饥饿
        - 效率不高
   3. C-Scan (Elevator)
      - 只是从外到内，再置位到最外道
      - 优缺点：
        - 所有磁盘更平
   4. 最短定位时间第一 (Shotest Positioning Time First)
      - 考虑到硬盘旋转的方向。寻道时间与旋转时间的问题
      - 优缺点：
        - 性能高
        - 实现较困难，操作系统通常不知道轨道边界在哪里或者磁头现在在哪里。

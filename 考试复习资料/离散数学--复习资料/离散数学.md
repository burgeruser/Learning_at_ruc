# 离散数学

## 命题逻辑

### 范式

**主析取范式**：形如：$P \or Q$，其中 $P,Q$ 为极小项

​	**极小项**：简单**合取式**，形如：$p \wedge q$，满足**成真赋值**

| 成真赋值 | 公式                   | 名称  |
| -------- | ---------------------- | ----- |
| 0 0      | $\neg p \wedge \neg q$ | $m_0$ |
| 0 1      | $\neg p \and q$        | $m_1$ |
| 1 0      | $p \and \neg q$        | $m_2$ |
| 1 1      | $p \and q$             | $m_3$ |

**主合取范形**：形如：$P \and Q$，其中 $P, Q$ 为极大项

​	**极大项**：简单的**析取式**，形如：$p \or q$，满足**成假赋值**

| 成假赋值 | 公式                | 名称  |
| -------- | ------------------- | ----- |
| 0 0      | $p \or q$           | $M_0$ |
| 0 1      | $p \or \neg q$      | $M_1$ |
| 1 0      | $\neg p \or q$      | $M_2$ |
| 1 1      | $\neg p \or \neg q$ | $M_3$ |

### 二元关系

**集合 $A(|A|=n)$ 上可以有从少个二元关系？定义多少种不同的等价关系？多少种对称关系？多少个即对称又反对称的关系？**

- 二元关系个数有： $2^{n \times n} = 2^{n^2}$

- 不同的等价关系（等价关系与划分一一对应）：
  - 例 $A = \{1, 2, 3\}$，有5种划分，分别是 
    - $R_1 = \{\{1\}, \{2\}， \{3\}\}$
    - $R_2 = \{\{1\}, \{2, 3\}\}$
    - $R_3 = \{\{1, 2\}, \{3\}\}$
    - $R_4=\{\{1, 3\}, \{2\}\}$
    -  $R_5\{\{1, 2, 3\}\}$，
    - 对就的等价关系为$R_1 = \{<1,1>, <2, 2>, <3, 3>\}$ 等等
    - 一般规律请参考[[集合A(|A|=n)上可以定义多少种不同的等价关系_等价关系个数_林晚慕的博客-CSDN博客](https://blog.csdn.net/sinat_20471177/article/details/117652278)]

- **有多少个即对称又反对称的关系？**
  - 对称关系对应的矩阵的特点是：对角线上的项可以是 0 或 1，其余项必须成对满足 $m_{ij}=m_{ji}$；反对称关系，主对角线上的项可以是 0 或 1，其余项  $m_{ij} = 1$ 时， $m_{ji} = 0$。所以 $m_{ij}=m_{ji}= 0$：
    1. 主对角线上的项可以是 0 或 1，所以有 $2^n$ 种方案
    2. 对主对角线外的 $n^2 - n$ 个元素，因为经使得 $m_{ij} = m_{ji}=0$，只有一种方案：
    3. 根据乘法原则，一共是 $2^n \cdot 1 = 2^n$
  - **下面这种解析不完整**
  - 将 $A\times A$ 中的元素分为三部分：第一部分是 $n$ 个 $<a, a>$ 类型的序偶，第二部分是 $n(n-1) / 2$ 个 $<a, b>$ 类型的序偶，第三部分是 $n(n-1) / 2$ 个 $<b, a>$ 类型的序偶。
    - $A$ 上对称关系的个数 = $(C_{n(n-1)/2}^0 + C_{n(n-1)/2}^1 + \cdots + C_{n(n-1)/2}^{n(n-1)/2})(C_{n}^{0} + C_{n}^{1} + \cdots + C_{n}^{n}) = 2^{n(n-1)/2} \cdot 2^n = 2^{n(n+1)/2}$
    - $A$ 上反对称关系的个数与 $A$ 上的对称关系的个数相等 = $2^{n(n+1)/2}$

- **有几个不同的自反关系？**
  - 自反关系主对角线上全是1，其余项可以是 0 或 1。
    1. 主对角线上全是 1， 只有 1 种方案，
    2. 主对角线外有 $n^2 - n$ 个元素，可能是 0 或 1，共有 $2^{n^2 - n}$
    3. 所以一共是 $1 \cdot 2^{n^2 - n}$

- **有几个反自反关系？**
  - 反自反对应的矩阵的特点是：对角线上的项全是 0，其余项可以是 0 或 1。
    1. 主对角线上的 $n$ 项全是 0，只有 $1$ 种方案
    2. 通过将 $n^2 - n$ 步将主对角线外的元素可以设置为 0 或 1，方案数有 $2^{n^2 - n}$
    3. 所以一共是 $1 \cdot 2^{n^2 - n}$
- **有几个对称关系？**
  - 对称关系对应的矩阵的特点是：对角线上的项可以是 0 或 1，其余项必须成对满足 $m_{ij} = m_{ji}$，因此可以按以下步骤：
    1. 主对角线上的项可以是 0 或 1，所以有 $2^n$ 种方案
    2. 对主对角线外的 $n^2 - n$ 个元素，因为经使得 $m_{ij} = m_{ji}$，所以一个可以有 $(n^2 - n) /2$ 步，而 $m_{ij}$ 可以是 0 或 1，所以一共有 $2^{(n^2 - n)/2}$ 种方案
    3. 根据乘法原则，一共是 $2^n \cdot 2^{(n^2 - n)/2} = 2^{(n^2 + n)/2}$
- **有几个不同的反对称关系？**
  - 对称关系对应的矩阵的特点是：对角线上的项可以是 0 或 1，其余项必须成对满足 $m_{ij} = 1$ 时， $m_{ji} = 0$，因此可以按以下步骤：
    - 主对角线上的项可以是 0 或 1，所以有 $2^n$ 种方案
    - 对主对角线外的 $n^2 - n$ 个元素，因为经使得 $m_{ij} = m_{ji}$，所以一个可以有 $(n^2 - n) /2$ 步，而 $m_{ij}$ 的设置有 3 种情况：
      - $m_{ij} = 1, m_{ji}=0$ 
      - $m_{ij} = 0, m_{ji}=1$ 
      - $m_{ij} = 0, m_{ji}=0$ 
      - 因为这就有 $3^{(n^2 - n)/2}$
    - 根据乘法原则，一共是 $2^n \cdot 3^{(n^2 - n)/2}$

- **有几个不同的自反且对称的关系？**
  - 对称关系对应的矩阵的特点是：对角线上的项可以是 1，其余项必须成对满足 $m_{ij} = 1$ 时， $m_{ji} = 0$，因此可以按以下步骤：
    1. 主对角线上的项可以是 1，所以有 $1$ 种方案
    2. 对主对角线外的 $n^2 - n$ 个元素，因为经使得 $m_{ij} = m_{ji}$，所以一个可以有 $(n^2 - n) /2$ 步，而 $m_{ij}$ 可以是 0 或 1，所以一共有 $2^{(n^2 - n)/2}$ 种方案
    3. 根据乘法原则，一共是 $2^n \cdot 2^{(n^2 - n)/2} = 2^{(n^2 + n)/2}$

- **有几个不同的自反且对称关系？**
  - 对称关系对应的矩阵的特点是：对角线上的项可以是 1，其余项必须成对满足 $m_{ij} = m_{ji}$，因此可以按以下步骤：
    1. 主对角线上的项可以是 1，所以有 $1$ 种方案
    2. 对主对角线外的 $n^2 - n$ 个元素，因为经使得 $m_{ij} = m_{ji}$，所以一个可以有 $(n^2 - n) /2$ 步，而 $m_{ij}$ 的设置有 3 种情况：
       - $m_{ij} = 1, m_{ji}=0$ 
       - $m_{ij} = 0, m_{ji}=1$ 
       - $m_{ij} = 0, m_{ji}=0$ 
       - 因为这就有 $3^{(n^2 - n)/2}$
    3. 根据乘法原则，一共是 $1 \cdot 3^{(n^2 - n)/2}$

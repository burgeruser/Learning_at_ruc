# 国考计算机综合复习资料

> 国考（全国统考）计算机综合 = **数学 40 分**（组合数学 + 离散数学必考）+ **五选二各 30 分**（计算机网络 / 软件工程 / 系统结构 / 人工智能 / 图形学）。60 分及格，成绩保留 4 年。

## 说明

- 组合数学、离散数学的综合笔记已统一放在课程目录 `10_组合数学` 与 `11_离散数学`，与国考数学共用（见 [数学/README.md](数学/README.md)）。
- 五选二建议优先选题库考 / 期末已复习过的科目（如计算机网络、软件工程），复用已有资料，省时省力。
- 原资料中「读研教育」培训班的资料可能含较多错误，请自行斟酌。
